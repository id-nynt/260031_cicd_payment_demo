# Execution guidelines

**Existing setup, newly updated app:** start with [06: Refresh the v1/v2 pair](06_REFRESH_VERSION_PAIR.md). This creates new source tags and a fresh verified v1 receipt without reinstalling tools or registering a runner again.

1. [Environment checklist](01_ENVIRONMENT_CHECKLIST.md) — shared prerequisites and links to each manual's setup procedure.
2. [Comparative execution](02_COMPARATIVE_EXECUTION_GUIDE.md) — shared scenarios, matched policy and experimental limitations.
3. [BDI manual](03_BDI_MANUAL_EXECUTION_GUIDE.md) — end-to-end agent execution; C6 is the paired-study route.
4. [Conventional manual](04_CONVENTIONAL_MANUAL_EXECUTION_GUIDE.md) — independent GitHub Actions setup, baseline, reset and execution.
5. [Results inspection](05_EXPERIMENT_RESULTS_GUIDE.md) — evidence locations, relevant outputs, metrics and comparison reports.
6. [Refresh the version pair](06_REFRESH_VERSION_PAIR.md) — returning-user procedure after an app change, including the visible v1/v2 heading.

Choose manual 03 or 04 for the current trial; reset before every measured trial. Read 05 for both. Within the BDI manual, C6 is the paired-study route; C0–C5 and D are optional diagnostic or goal demonstrations, not extra required study steps.
